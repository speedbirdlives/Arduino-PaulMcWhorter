STARTING OFF WITH ELECTRONICS!!

After my 12th boards, I had a long set of holidays. I was going to do Electronics and Communications Engineering for my Bachelors degree. Thus I decided to do something related to electronics in my holidays.

I started off with a simple YouTube series on Arduino UNO by Paul McWhorter. 
This series is completely free. I have insterted a link for the series in the repository.

Essentials: Arduino UNO starter kit. Arduino NANO. There are also a few other instruments and components Paul mentions further into the series which you may have to buy.

Prerequisites: Basic understanding of current and circuits, semiconductors, linear algebra, and simple programming. Paul taes his time to explain everything in detail, so you don't necessarily have to do the prerequisites, if you can understand them from him.

This repository consists of certain small projects I made using all the fundamentals taught by Paul. It also consists mostly of Paul's projects and homework he gave throughout the series.

This repository was made roughly a month after I completed the series.

Even though I have given the option for you to create pull requests and make seperate branches, I would advise you to fork the entire repository and make whatever changes you need. This is because I want to preserve my code in a sense that it must seem like a beginner's work on basic microcontrollers.

I have attatched some videos of these projects in the repository. They are not necessarily in the same order.
The repository also contains libraries for certain components/modules. Make sure to use them when using the respective components/modules.
